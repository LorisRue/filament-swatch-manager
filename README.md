# Filament Swatch Manager

A web app for managing 3D‑printing filament swatches. Print a swatch with an ID, then store metadata (material, brand, color, print settings, etc.).

## Why this project

Keeping track of multiple filament swatches / samples gets chaotic. This tool lets you associate a physical swatch with a digital entry.

## Features

- Unique identifier per swatch
- Store color, material, brand, temps, etc.
- Search/filter your filament library

## Tech Stack

- Next.js + TypeScript
- Supabase (PostgreSQL) backend

## Setup

### 1. Clone & install

```bash
git clone https://github.com/LorisRue/filament-swatch-manager.git
cd filament-swatch-manager
npm install
```

### 2. Supabase database

Create a new Supabase project. In SQL editor run:

```sql
create table public."Filaments" (
  id bigint generated by default as identity not null,
  created_at timestamp with time zone not null default now(),
  identifier text not null,
  type text not null,
  color text not null,
  "colorHex" text not null,
  material text not null,
  brand text not null,
  diameter real not null,
  cost numeric null,
  supplier text null,
  weight smallint not null,
  "weightLeft" smallint null,
  "inStock" boolean not null,
  "dateAdded" date not null,
  notes text null,
  "nozzleTemp" numeric null,
  "bedTemp" numeric null,
  "flowRatio" numeric null,
  "pressureAdvance" numeric null,
  "retractionDistance" numeric null,
  "maxVolumetricSpeed" numeric null,
  constraint Filaments_pkey primary key (id),
  constraint Filaments_identifier_key unique (identifier)
);
```

### 3. Environment variables

Copy `.env.example` to `.env` and fill in your Supabase URL and anon/public key.

### 4. Development

```bash
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000)
