# Contributing to Filament Swatch Manager

Thank you for considering contributing!

## Issues

- For bugs: include steps to reproduce
- For features: explain the use case

## Getting Started

1. Fork this repository
2. Clone your fork and install dependencies:

```bash
git clone https://github.com/LorisRue/filament-swatch-manager.git
cd filament-swatch-manager
npm install
```

3. Create a feature branch:

```bash
git checkout -b feature/your-feature-name
```

4. Copy `.env.example` to `.env` and fill Supabase credentials
5. Start development server:

```bash
npm run dev
```

## Pull Request Guidelines

- Keep PRs focused and concise
- Ensure the app builds and runs without errors
- If UI-related, include screenshots or gifs
- Describe what the change does and why

## Commit Style

Use descriptive commit messages, e.g.:

```
feat: add filament color preview
fix: resolve missing env var crash
```

Thank you for contributing!
